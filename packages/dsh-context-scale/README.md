# dsh-context-scale

Мини-шкала заполнения контекстного окна под полем ввода. Две метки-порога можно перетаскивать прямо на шкале: предупреждение и автосжатие.

## Что делает

- показывает живое заполнение контекста текущей сессии;
- две перетаскиваемые метки: порог предупреждения и порог автосжатия;
- при переходе второго порога host-половина запускает `/compact` для простаивающего агента (кулдаун 20 секунд).

## Установка

Через индекс маркета: DSH → **Plugins → Discover → Add index source** →
`https://ushmask.github.io/dsh-plugins/index.json`, затем **Install** у карточки плагина.

Вручную: скопируйте install-spec из карточки плагина (или из `site/index.json`) и выполните

```sh
dsh plugin --profile <profile> add <spec>
```

## Настройки

Значения по умолчанию задаёт `cordis.patch.yml`; переопределить их можно в `cordis.patch.yml` профиля:

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `warnPct` | `55` | Порог предупреждения, % |
| `compactPct` | `80` | Порог автосжатия, % |
| `autoCompact` | `true` | Запускать `/compact` при переходе второго порога |

```yaml
- id: context-scale
  name: dsh-context-scale
  config:
    warnPct: 60
    compactPct: 85
    autoCompact: false
```

Пороги, сдвинутые мышью в UI, сохраняются в `localStorage` браузера.

## Совместимость

DSH `>=0.2.2-rc.1 <0.3.0`, Web UI. Пакет уже собран: host-половина — `index.js`, клиентская — `client.js`; сборка при установке не нужна.
