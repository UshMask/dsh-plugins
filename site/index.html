Плагины Max для DSH

Индикаторы заполнения контекста и стоимости токенов для Web UI DeepSeek Harness.

Как поставить плагины
  1. В DSH включите экспериментальный бандл Custom plugin market (Plugins → More рядом с «Experimental plugins»).
  2. Plugins → Discover → Add index source и вставьте https://ushmask.github.io/dsh-plugins/index.json.
  3. Выберите плагин и нажмите Install — DSH покажет версию, источник и коммит.

Командная строка для ручной установки: dsh plugin --profile <profile> add <spec>, spec указан в карточке.

Шкала контекста Context scale

Минимальная шкала заполнения контекста под полем ввода с двумя перетаскиваемыми метками: порог предупреждения и порог автосжатия.

Стоимость токенов Token cost

Заменяет текст о расходе токенов компактной оценкой стоимости и объясняет простыми словами, что значат кэшированный ввод, некэшированный ввод, попадание в кэш и выход.
